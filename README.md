# AZON — متجر المنتجات الرقمية

واجهة المتجر بالكامل جديدة (أزرق وأسود) + لوحة تحكم مأخوذة من ملفك.

## التشغيل
```bash
npm install
cp .env.example .env     # عبّي المفاتيح
npm start                # http://localhost:4500
```
يحتاج Node.js 22.5 أو أحدث.

أول تشغيل يطبع كلمة مرور أدمن عشوائية بالـ terminal (المستخدم: admin)، وبتجبرك على تغييرها.
لوحة التحكم: /admin/login

## الدفع (داخل الدرج الجانبي، بدون صفحة دفع)
السلة ← الدفع ← تتبع الطلب، كلها داخل نفس الدرج.
- بطاقة + Apple Pay + Google Pay عبر Stripe Payment Element (تظهر الأزرار تلقائياً حسب جهاز العميل).
- PayPal داخل نفس الدرج.
- بعد الدفع: شاشة تتبع لحظية (تم الدفع ← قيد التجهيز ← تم التسليم) وعرض الأكواد.
- إشعار ديسكورد للعميل عند الدفع والتسليم (يحتاج `DISCORD_BOT_TOKEN` وأن يكون العميل بنفس سيرفر البوت أو يسمح بالرسائل الخاصة).
- Apple Pay: فعّل الدومين من Stripe Dashboard ← Settings ← Payment methods ← Apple Pay بعد رفع الموقع.
- أضف Webhook في Stripe على `/webhooks/stripe` للحدث `payment_intent.succeeded` (احتياطي للتأكيد).

## المفاتيح (.env)
- `STORE_SECRET_KEY` — نص عشوائي طويل (إلزامي بالإنتاج)
- `DISCORD_CLIENT_ID / SECRET / REDIRECT_URI` — تسجيل الدخول عبر ديسكورد
- `STRIPE_PUBLISHABLE_KEY` + `STRIPE_SECRET_KEY` + `STRIPE_WEBHOOK_SECRET` — الدفع بالبطاقة
- `DISCORD_BOT_TOKEN` — إشعارات خاصة للعميل (اختياري)
- `PAYPAL_CLIENT_ID / SECRET / PAYPAL_ENV`

## الصفحات
الرئيسية، من نحن (/about — نصوصها تتعدل من لوحة التحكم: "من نحن (About)")، أقسام (/category/:slug)، كل المنتجات، بحث، صفحة منتج، سلة (درج جانبي + صفحة)، كوبونات، دفع، طلباتي، المفضلة، التقييمات (للمشترين فقط)، الصفحات القانونية.

## لوحة التحكم
الطلبات، السلات المتروكة، المنتجات (+أكواد التسليم والمخزون)، الأقسام، الكوبونات، الأسئلة الشائعة، التقييمات، محتوى الموقع، فريق العمل، سجل الأخطاء.

## تغيير الألوان

## الأمان (جاهز بالكود)
- **تحقق بخطوتين (2FA) للأدمن:** من لوحة التحكم ← Security (2FA). لو ضاع الجوال: `node scripts/reset-2fa.js <username>`. لإجبار كل الأدمنز: `ADMIN_REQUIRE_2FA=1`.
- **قفل لوحة التحكم على عناوين IP:** `ADMIN_ALLOWED_IPS=1.2.3.4,5.6.7.8`
- حماية CSRF، قفل محاولات الدخول الفاشلة، تجديد الجلسة بعد تسجيل الدخول، ومنع إعادة التوجيه الخارجية.
- كوكي آمن + HSTS في الإنتاج (شغّل `NODE_ENV=production` و`TRUST_PROXY=1` خلف HTTPS).
- **حماية الطلبات:** حد للطلبات غير المدفوعة (`MAX_PENDING_ORDERS`)، ومنع الحسابات الجديدة جداً (`MIN_DISCORD_ACCOUNT_DAYS`)، والطلبات الكبيرة تنتظر مراجعتك قبل تسليم الأكواد (`REVIEW_THRESHOLD_USD`).
- **نسخ احتياطي تلقائي** يومياً بمجلد `backups/` (يحتفظ بآخر 14 نسخة) — انسخه لمكان خارج السيرفر دورياً.
- **تنبيهات على ديسكورد** (Webhook اللوحة) عند أي خطأ بالموقع أو طلب كبير.
- **من Stripe Dashboard:** فعّل Radar (كشف الاحتيال) واستعمل مفاتيح مقيّدة.
- لا ترفع `.env` ولا `store.db` على GitHub أبداً.

## ميزات إضافية
- تقييم لكل منتج (للمشترين فقط) + تقييمات عامة.
- رابط تتبع قابل للمشاركة `/track/<token>` بدون أكواد.
- تذكير السلات المتروكة عبر ديسكورد (يحتاج `DISCORD_BOT_TOKEN`).
- SEO: Open Graph، بيانات منتج منظّمة (JSON-LD)، sitemap وrobots.
- الخطوط على السيرفر نفسه (بدون Google Fonts)، وتحويل صور المنتجات تلقائياً إلى WebP وإزالة بيانات الموقع منها.
- إحصائيات إضافية بالداشبورد: متوسط الطلب، التحويل، العملاء المتكررين، إيراد 30 يوم.

## لوحة التحكم الجديدة (عربي كامل)
- **لوحة القيادة:** مبيعات اليوم، رسم بياني (7/30/90 يوم)، حالات الطلبات، طلبات تحتاج إجراء، مخزون منخفض، الأكثر مبيعاً، مصادر المبيعات، آخر النشاط، وتنبيه إذا المتجر غير جاهز.
- **بحث سريع Ctrl+K** للانتقال لأي صفحة أو طلب أو منتج أو عميل.
- **رفع الصور:** سحب وإفلات أو لصق (Ctrl+V) أو من المكتبة، حتى 20MB، تُحوَّل لـ WebP وتُخزَّن بقاعدة البيانات (لا تختفي مع إعادة النشر). متاحة للمنتجات، وبانر الأقسام، والشعار، وأيقونة الموقع، وخلفية الرئيسية.
- **الأكواد:** لكل منتج "طريقة تسليم": أكواد تلقائية / تسليم يدوي / تسعير مخصص. الأكواد مشفّرة (AES-256-GCM)، المكرر يُتجاهل، المخزون يتحدث تلقائياً، وتنبيه ديسكورد عند قرب النفاد. تسليم يدوي من صفحة الطلب أيضاً.
- **العملاء:** قائمة، ملاحظات داخلية، وحظر.
- **الأقسام والمحتوى والتقييمات والأسئلة والكوبونات وروابط التواصل ومكتبة الصور.**
- **الإعدادات والجاهزية:** قائمة تتأكد من المفاتيح، ووضع الصيانة، واختبار تنبيهات ديسكورد.
- **الفريق والصلاحيات:** موظفون بصلاحيات مفصّلة (الطلبات، المنتجات، الأكواد، العملاء، التسويق، المحتوى).
- **سجل نشاط الإدارة**، **النسخ الاحتياطي** (إنشاء وتنزيل)، **الجلسات النشطة** مع إنهائها.
- **مفتاح التشفير:** خذ نسخة من `CODES_KEY` (أو ملف `codes.key`) بمكان آمن — بدونه لا تُقرأ الأكواد المخزنة.
